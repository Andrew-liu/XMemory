XMemeory 是一款本地优先的桌面写作 App，将短推灵感、参考资料和长文选题放在同一个工作区。内容直接保存为 Markdown，支持外部编辑和个人私有仓库同步。

## 灵感

- 默认按周展示，可切换查看整月。
- 每天输入标题即可快速记录，点击灵感展开正文。
- 一个灵感就是一条待办，已使用的灵感勾选划线，支持撤销。
- 未完成的灵感保留在当天，不催办；同一天未完成项排在前面。
- 支持拖动调整顺序或移动到其他日期。

## 选题

- 独立记录长文想法，每个选题是一条待办。
- 点击选题，在同一篇文档中编写大纲和长文。
- 已写完的选题划线，未完成项始终排在已完成项前面。
- 支持继续编辑、撤销完成和搜索历史选题。

## 记忆

- 粘贴一条 X 推文或长文链接即可采集，保存正文、原文链接和原图，不下载视频文件。
- 一键批量采集 X 书签：每次可选 20 / 50 / 100 条，已采集过的自动跳过；暂停或退出后再次采集即可接着往下。
- 书签采集自带限额与保护：每天最多新增 200 条（其中长文 50 篇），单次最长 30 分钟；遇到登录验证、限流或连续失败会立即停止并说明原因，不自动重试。
- 长文保留标题、列表、引用、代码块、封面和原位配图，内嵌视频保留封面；短推的短链接还原为真实地址。
- 提供列表与卡片视图，可按正文、作者和媒体类型筛选。
- 显示图片保存结果，失败时保留远程链接，支持重新采集；重新采集不覆盖自己的笔记，原先不完整的内容可通过重新采集补全。

> 采集使用本机正式版 Google Chrome 的独立 Profile，首次需在 Chrome 中手动登录 X。书签采集需手动点击开始，不定时自动采集；不采集推文串、回复和引用推文正文。

## 编辑与图片

- Markdown 源码与富文本切换，支持表格、链接、双向链接和笔记摘要嵌入。
- 自动保存，支持在外部编辑 Markdown 后回读。
- 直接粘贴图片到正文，图片保存在本地。
- 双击放大图片、查看原始尺寸、右键复制；另提供邮件富文本复制。
- 导出当前笔记的 Markdown 和正文直接引用的本地图片，不携带其他笔记或无关附件。

## 候选稿

v0.5.1 起移除了 AI 创作与模型配置。此前生成的候选稿仍保留在资料库中，可通过全局搜索打开、编辑并返回原灵感，也照常参与同步。

## 全局搜索

- 搜索已保存的灵感、记忆、选题和候选稿。
- 支持类型、作者、标签和日期筛选。
- 高亮标题与摘要中的命中内容，点击结果滚动并选中正文匹配位置；源码中的匹配可切换源码定位。

## 私有同步与数据管理

- 内容保存在本地，正文采用 Markdown，可用其他编辑器打开。
- 支持 GitHub 私有仓库双向同步；配置完成后，应用每次启动会在后台同步一次，运行期间每 10 分钟继续检查，也可手动触发。
- 每次同步先检查远端是否有新提交：有更新先拉取并合并到本地，再上传本地修改；上传时若远端又有变化，自动重新拉取后重试（最多 3 次）。远端没有更新时不重复下载。
- 同步跳过未变化文件的下载，复用已校验的本地内容或缓存；显示本轮拉取、上传、下载与复用数量。
- 冲突时保留双方，展示正文与附加字段差异，可选择版本、保留两份或手动合并。
- 仅换行格式或 YAML 写法不同、实际内容相同时，不新增同步冲突。
- 删除的内容进入回收站，支持恢复。
- GitHub Token 在本机加密保存，不参与资料库同步。

## 外观

- 浅色、深色和跟随系统主题。
- 简洁的侧栏与编辑工作区。
- 支持关闭窗口后驻留托盘。
- 可在设置中开启开机自启（默认关闭，仅安装版可用）；开机后只在托盘中启动，不弹出窗口，也不会自动采集。
