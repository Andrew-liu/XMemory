XMemeory 是一款本地优先的桌面写作 App，将短推灵感、参考资料和长文选题放在同一个工作区。内容直接保存为 Markdown，支持外部编辑和个人私有仓库同步。

## 灵感

- 默认按周展示，可切换查看整月。
- 每天输入标题即可快速记录，点击灵感展开正文。
- 一个灵感就是一条待办，已使用的灵感勾选划线，支持撤销。
- 未完成的灵感保留在当天，不催办；同一天未完成项排在前面。
- 支持拖动调整顺序或移动到其他日期。

## 选题

- 独立记录长文想法，每个选题是一条待办。
- 点击选题，在同一篇文档中编写大纲和长文。
- 已写完的选题划线，未完成项始终排在已完成项前面。
- 支持继续编辑、撤销完成和搜索历史选题。

## 记忆

- 保存参考内容的正文、原文链接和图片，不下载视频文件。
- 提供列表与卡片视图，可按正文、作者和媒体类型筛选。
- 显示图片保存结果，失败时保留远程链接，支持重新采集。
- 保留自己的笔记，方便后续查阅和作为创作素材。

> 当前采集仅开放两条固定内容的定向测试，全量历史书签归档和定时新增书签采集尚未开放。

## 编辑与图片

- Markdown 源码与富文本切换，支持表格、链接、双向链接和笔记摘要嵌入。
- 自动保存，支持在外部编辑 Markdown 后回读。
- 直接粘贴图片到正文，图片保存在本地。
- 双击放大图片、查看原始尺寸、右键复制；另提供邮件富文本复制。
- 导出当前笔记的 Markdown 和正文直接引用的本地图片，不携带其他笔记或无关附件。

## AI 创作

- 在灵感内选择 DeepSeek 或 OpenAI Chat Completions 兼容服务，根据当前标题、正文和参考素材生成短推或串文。
- 支持本地资料检索，并可通过联网工具搜索、读取公开网页。
- 支持新增、编辑、删除多份模型配置，各自保存独立 Key；设置页与创作面板可切换，重启记住选择。
- 可填写写作要求、选择素材、停止生成和复制结果。
- 生成内容保存为候选稿，并记录所用服务和模型，可从原灵感或全局搜索找回。

> 联网检索由应用接入的 Jina 工具提供；支持 DeepSeek 和 OpenAI Chat Completions 兼容接口，所选模型需支持流式输出与工具调用；暂不支持 Claude/Gemini 原生协议。选题暂不包含长文 AI 生成。

## 全局搜索

- 搜索已保存的灵感、记忆、选题和候选稿。
- 支持类型、作者、标签和日期筛选。
- 高亮标题与摘要中的命中内容，点击结果滚动并选中正文匹配位置；源码中的匹配可切换源码定位。

## 私有同步与数据管理

- 内容保存在本地，正文采用 Markdown，可用其他编辑器打开。
- 支持 GitHub 私有仓库双向同步；配置完成后，应用每次启动会在后台同步一次，运行期间每 10 分钟继续检查，也可手动触发。
- 同步跳过未变化文件的下载，复用已校验的本地内容或缓存；显示本轮下载与复用数量。
- 冲突时保留双方，展示正文与附加字段差异，可选择版本、保留两份或手动合并。
- 仅换行格式或 YAML 写法不同、实际内容相同时，不新增同步冲突。
- 删除的内容进入回收站，支持恢复。
- API Key 和 GitHub Token 在本机加密保存，不参与资料库同步。

## 外观

- 浅色、深色和跟随系统主题。
- 简洁的侧栏与编辑工作区。
- 支持关闭窗口后驻留托盘。
